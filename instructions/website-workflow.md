# Website workflow

Use website-companion for website planning, mockups, and WordPress/Elementor work. Use Impeccable for design guidance and the Superpowers visual companion for clickable browser previews according to the saved preferences.

For website planning, mockups, copy, styling, and Elementor edits, explicitly skip Superpowers TDD, unit-test scaffolding, worktrees, and mandatory software spec/implementation-plan workflows. Follow the website skill's conversational planning and design decisions instead. Verify saved Elementor content and inspect desktop/mobile previews where tools permit. For custom functional code, use tests appropriate to the behavior and risk.

Keep each client's context in that project's folder. Keep new pages as drafts and publish only on explicit request.
